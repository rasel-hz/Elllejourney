# Elle's Journey 🎮✨

A 2D adventure game built entirely from scratch in **Java**, featuring custom graphics, multiple maps, and a custom **AI Engine** for smart monster behavior and pathfinding.

---

## 🌟 About the Game

**Elle's Journey** follows the story of Elle as she navigates through challenging maps. Players must collect items, fight enemies using dynamic combat mechanics, and survive until they reach the final destination. 

---

## 🚀 Key Features

- **Custom Artwork:** Hand-crafted graphics, sprites, and assets designed specifically for the game.
- **Custom AI Engine:** Implemented smart monster tracking and behavior algorithms to hunt/follow the player across the map.
- **Multiple Maps & Levels:** Progress through diverse environments with increasing difficulty.
- **Item Collection & Combat System:** Interactive inventory/item gathering paired with engaging combat mechanics.
- **Built with Pure Java:** Developed using object-oriented principles without heavy external game engines, ensuring deep control over game loops and rendering.

---

## 🛠️ Tech Stack

- **Language:** Java
- **Concepts:** Object-Oriented Programming (OOP), Game Loops, 2D Rendering, Artificial Intelligence (Pathfinding & State Machines).
